# 面板

> **English (source of truth)**: [../HUD.md](../HUD.md)

计时器是一个 IMGUI 文本浮层,**直接绘制在屏幕上** —— 无窗口、无背景、不可拖动。行可自由编排,文字支持逐字符双色渐变。

## 行类型

每行渲染一个值:

| 行类型 | 显示 |
|--------|------|
| `GameTime` | 本局累计的游戏时间 |
| `RealTime` | 本局墙钟用时(默认显示在第二列,见下文) |
| `PrevRt` | **上关RT**:上个单段完成那一刻定格的现实时间 —— `TotalAtLastSegment` 的现实时间对应物(整局累计快照,而非该关的现实用时)。默认显示在第二列 `RealTime` 正下方 |
| `CurrentSegment` | 进入当前关卡至今的时间 |
| `TotalAtLastSegment` | 上个单段完成那一刻定格的总时间 |
| `LastSegment` | 上一个完成关卡的用时 |
| `LastRun` | 上一次完整尝试的总时间 —— 与其它行相同的普通行(默认放进第三列),仅空闲时显示(新局开始计时即隐藏) |
| `WakeUpTime` | **起身时间**(默认显示在第三列 `LastRun` 下方):从最近一次“可起身起点”到本地玩家离开瘫软状态的时间,格式 `SS:mmm` |
| `CurrentState` | 引擎检测到的游戏状态(调试) |

## 列

行被分组到**列**中。`layout.ini` 的每个 `[column.<n>]` 节存放一列的若干行,**每个键是该行在列内的 1 基位置**(位置不可重复;永远不会写入 `0`)。列按编号**从左到右**绘制 —— `[column.1]` 是最左的计时列、`[column.2]` 是第二列,依此类推 —— 整个文本块锚定在 `offset_x` / `offset_y`。**没有行的列不显示**、也不占空间。默认布局(首次安装时写入一次):

```ini
[column.1]
1 = GameTime
2 = CurrentSegment
3 = TotalAtLastSegment
4 = LastSegment

[column.2]
1 = RealTime
2 = PrevRt

[column.3]
1 = LastRun
2 = WakeUpTime
```

`RealTime` 与 `PrevRt` 默认放进 `[column.2]`(`PrevRt` 位于 `RealTime` 正下方);`LastRun` 与 `WakeUpTime` 默认放进 `[column.3]`(即原先的“右侧列”)。**所有行类型 —— 包括 `LastRun` 和 `WakeUpTime` —— 都是可在列间自由移动的普通行**;面板 **界面 → 计时器HUD** 的列编辑器编辑的正是这些位置(`0` 表示隐藏),空列只是隐藏。

> **旧版 `[rows]` 配置**:旧 `layout.ini` 把行存在扁平的 `[rows]` 节中。它们仍可加载(在内存中映射到 `[column.1]`),并在下次保存时改写为 `[column.N]` 格式;启动时不再做任何迁移或自动修改。

## 起身时间

**起身时间**是普通 HUD 行(默认在第三列 `LastRun` 下方)。默认情况下,它指从最近一次“可起身起点”到本地玩家角色离开瘫软状态(`Spawning` / `Unconscious` / `Dead`)的时间。可起身起点包括:本关开始、玩家重生(如坠落/死亡后)、从暂停菜单**加载存档点**、从暂停菜单**重新开始关卡** —— 之后显示的是“这次起身”用了多久。单次测量内,后续手动装死不会重置该值;下一次重生 / 重新开始会清除并重新开始计时。

开启 **仅记录第一次起身时间**(在 **界面 → 计时器HUD** 中)后恢复原机制:只记录本关开始后的第一次起身,后续重生、加载存档点或重新开始关卡都不再重置该值。关卡通过或退出时清除显示。

数值格式为 `SS:mmm`(秒和毫秒,不显示分钟/小时),本关首次测量前显示 `--:--`。通过面板 **界面 → 计时器HUD** 的列编辑器把该行的位置设为 `0` / 非零即可隐藏 / 显示(或直接编辑 `layout.ini`)。

## 现实时间

除游戏时间行外,面板还有一台 **现实时间(Real Time)** 计时器,用于测量本局的墙钟用时。它与游戏时间同时开始,在过关加载、暂停等期间不间断累计,并在整局完成(通过最后一关)时与游戏时间同时停表;若中途退出到菜单,也会停止累计。

现实时间行**默认显示在第二列(`[column.2]`,与“游戏总时间”并列),且计时器始终在后台活跃**。`RealTime` 是常规行类型:在 `[column.N]` 中移动即可显示在你指定的位置,或直接移除 —— 无论如何时钟都会在后台继续累计。通过面板 **界面 → 计时器HUD** 的列编辑器勾选 / 取消该行即可显示 / 隐藏。

**上关RT(`PrevRt`)** 显示上个单段完成那一刻(与 `TotalAtLastSegment` 定格游戏时间的同一时刻,R1.4.1)定格的现实时间值。与那一行一样,它是该时刻的整局累计快照 —— 不是上一关自身的现实用时 —— 因此会随整局递增,并在每个完成的关卡更新一次。第一个关卡完成前显示 `--:--`;与 `TotalAtLastSegment` 相同的重置(自动重置、从菜单开始新局、手动重置)会清除它,一键重试保留。

## 计时标准指示

当 **"使用 plcc 计时标准"** 选项(R1.4.2)开启时,面板会在时间行正下方显示一行 **`plcc计时模式`**(英文:`plcc timing mode`),让当前计时模式在屏幕上可见。该行使用与计时行相同的双色渐变绘制;选项关闭(默认)时整行省略。

## 颜色与渐变

默认文本渐变为左→右双色混合。每个颜色以十六进制指定,可为 `RRGGBB`(不透明)或 `RRGGBBAA`(含透明度)。在 `layout.ini` 的 `[panel]` 中设置两者:

```ini
color_a = FF5272FF   # 起始色(粉红,完全不透明)
color_b = FF9A72FF   # 结束色
```

两个颜色相同则为单色。逐字符透明度来自透明度字节,因此可使文字在行内渐隐。

自定义文本(`[custom.<n>]`)各有自己的 `color_a` / `color_b`。

## 自定义文本

可在固定屏幕坐标放置任意数量的文本:

```ini
[custom.0]
x = 400
y = 50
text = {date} {time}
color_a = FFFFFFFF
color_b = CCCCCCCF
```

**模板变量**(自动替换):

| 变量 | 替换为 |
|------|--------|
| `{date}` | 当前日期(`YYYY-MM-DD`) |
| `{time}` | 当前时间(`HH:MM:SS`) |
| `{version}` | 插件版本 |
| `{collection}` | 当前 Level Collections 地图包名(或兜底) |
| `{category}` | 当前类别显示名 |
| `{gametime}` | 当前游戏时间 |
| `{realtime}` | 当前现实时间 |

未知的 `{token}` 保持原样。在文本中使用字面 `\n` 表示换行。

## 位置与大小

主文本块**直接绘制在屏幕上** —— 没有窗口或背景,也不可拖动。在 `layout.ini` 的 `[text]` 下调整位置与字号:

```ini
[text]
offset_x = 16   # 距左边的像素
offset_y = 16   # 距顶部的像素
font_size = 18  # 字号
```

自定义文本(`[custom.<n>]`)各自有绝对坐标 `(x, y)`,因此可出现在屏幕任意位置,不受主文本块偏移影响。

## 显示 / 隐藏

通过设置面板(默认键 `Home`)切换整个计时器的显示,或在 `settings.ini` 设 `show_hud = false`。

## 游戏加载/保存提示

游戏自带的“Loading / Saving”进度提示默认显示在右上角。若希望它移到画面顶部居中,可在 `settings.ini` 中启用 `center_loading_saving`,或在设置面板的“界面”页勾选“将‘加载/保存’提示移到顶部居中”。

## 无效提示

当本局被标记无效时(R5),面板内会出现红色提示列出原因。有效性选项见 [CONFIG.md](CONFIG.md)。

同样的红色样式也用于**指定重试关卡无效**(R6.5):启用重试目标指定后,如果填写的关卡英文名或创意工坊数字 id 无法解析,按下重试键时会在计时器面板中显示一条红色“指定的重试关卡无效”提示。该提示会一直保留,直到填入可解析的值并再次按重试,或关闭“指定重试关卡”选项。

## 字体

面板使用带 CJK 后备链的动态 OS 字体(PingFang / Microsoft YaHei / Noto Sans CJK ……),因此中日韩本地化文字可正确渲染。请在你的平台上验证渲染效果。
