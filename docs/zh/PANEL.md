# 设置面板

> **English (source of truth)**: [../PANEL.md](../PANEL.md)

设置面板(用 **设置键**,默认 `Home`,打开 / 关闭)可实时编辑所有可调选项 ——
改动即时生效,并在关闭面板或退出游戏时写入磁盘。面板包含以下内置标签页,以及其它插件通过
`ISettingsPanelTab` 注册的**额外标签页**(见 [EXTENDING.md](EXTENDING.md))。实现
`ILocalizableSettingsPanelTab` 的额外标签页会随 HSRTimer 的 **常规 → 语言** 选择一起切换;
额外标签页还可订阅 `SettingsPanelTabRegistry.SettingsSaved`,在 HSRTimer 保存时持久化自身配置。

> 作弊 / 变速 / 漂移检测(R5.1)始终开启,阈值为硬编码,刻意**不**在面板的任何地方暴露。

## 常规

- **计时** —— `auto_reset`、`restart_clears_forgivable`(暂停菜单重新开始时清除可原谅标记;见 [CONFIG.md](CONFIG.md)),以及重试目标指定(`retry_level_override_enabled` + `retry_level_override`)。开启“指定重试关卡”后会出现一个文本输入框,可填关卡的英文本地化名(不区分大小写)或创意工坊数字 id。无效值会在按下重试键时以计时器面板的红色无效样式提示;在主菜单中,有效值可直接通过重试键进入该指定关卡。暂停期间始终计时,菜单 / 大厅期间始终不计时,二者均无开关。
- **语言** —— 从已加载的语言集合中单选当前语言。"重新加载语言文件" 会重新扫描 `lang/*.txt`。实现 `ILocalizableSettingsPanelTab` 的外部标签页会自动跟随该选择。
- **按键绑定** —— 重置 / 重试 / 设置键 / 排行榜模式循环键。排行榜模式循环键让共享排行榜 HUD 在“关闭 → 分段对比 → 标记 → 关闭”之间循环。改绑方法:点击对应项,然后按下目标键。纯修饰键(Shift/Ctrl/Alt/Cmd)按下会被忽略。鼠标侧键(`Mouse3`–`Mouse6`)也可绑定;鼠标左 / 右键仍保留为普通 UI 操作,不可绑定。

## 界面

- **面板** —— `show_hud`;`show_real_time`(显示始终活跃的现实时间计时器);`show_wake_up_time`(在右侧列显示起身时间);`only_record_first_wake_up_time`(仅当起身时间显示开启时可见,开启后恢复“只记第一次起身”的原机制);`center_loading_saving`(将游戏自带的右上角"加载/保存"提示移到顶部居中);主文本块的横向 / 纵向偏移(`offset_x`、`offset_y`)、字号(`font_size`),以及双色渐变(`color_a`、`color_b`,每通道 RGBA 滑块)。

## 类别

- **规则标签** —— 所有已注册规则标签的多选(四个内置标签:`Checkpoint`、`NoCheckpoint`、`Jumpless`、`Voiceline`,以及其他插件注册的自定义标签 —— 见 [EXTENDING.md](EXTENDING.md))。勾选即启用该标签,取消即禁用。没有类别预设 —— 这个标签集合就是当前的规则集。改动即时生效,并在关闭 / 退出时写入 `tags.ini`。

## 分段对比(Subsegment)

- **分段对比** —— 启 / 禁用本地分段时间对比、PB 与手动加载采样路径、多关对比的初始项目,以及各项检测 / 结算详细参数。多关运行中项目仅当前局内自动升级(`Any%` ⊃ `Steam%` ⊃ `Dark%` ⊃ `Aztec%`),不会改写已保存设置;若所选项目完全没有数据,则回退到有数据的最小项目(仅当前局内)。排行榜模式循环键位于 **常规 → 按键绑定**;排行榜外观设置已移到下面的 **排行榜** 标签页。

## 排行榜(Leaderboard)

- **内容** —— 选择共享排行榜 HUD 显示什么:**分段对比**(参考时间比较)或**标记**(当前关卡的标记 feed)。模式循环键与下面的外观设置对两种模式都生效。
- **面板** —— 排行榜字号、横向偏移、纵向偏移(相对屏幕中心的固定顶部锚点;内容向下延伸)。
- **条目颜色** —— 排行榜条目三种状态的可配置颜色:领先 / 更快(默认绿色)、落后 / 更慢(默认红色)、持平 / 无数据(默认白色,显示为 `--`)。标记模式下即使显示绝对时间,颜色也始终体现与 PB 的领先 / 落后。
- **标记时间显示** —— (仅标记模式)每行触发的标记显示其绝对分段时间,还是与该标记 PB 的带符号差值。
- **显示的资料** —— (仅分段对比模式)页面底部提供每个 subsegment 资料的开关:**PB** 与加载目录下的每个顶层文件夹。只有勾选的资料会出现在排行榜中。过滤排序后仍按 `MaxLeaderboardEntries` 截断到前 N 项。

## 标记(Markers)

- **标记** —— 启 / 禁用标记模块,切换**标记编辑模式**(同时开启游戏内可视化、计时器 HUD 底部的醒目提示及其下方的 XYZ 轴向指示器),并按 **主梦境**(内置关卡)、**额外梦境**(editor pick 关卡)、**工坊** 浏览关卡;每个关卡按钮进入该关卡的标记页。
- **关卡页** —— **返回**按钮、该关卡标记列表(每行点击展开编辑器),以及底部的 **新建标记** 按钮(仅编辑模式显示)。
- **标记编辑器** —— 名称输入框 + 类型下拉(范围触发 / 存档点触发 / 抓取物体),各类型控件:范围触发含"设为玩家位置"、中心 / 边长输入、抓取 / 跳跃条件开关;存档点触发含存档点序号与可选的"从暂停菜单加载时触发";抓取物体含"设为当前抓取物体"(抓取超过一个物体时无效)与只读物体 id。标记可启用 / 禁用、删除(需确认),并只读显示当前 PB 时间。
- 编辑模式关闭时,展开的标记仅只读展示。

各标签的作用见 [CATEGORIES.md](CATEGORIES.md),Checkpoint 标签的规则见 [CHECKPOINTS.md](CHECKPOINTS.md),标记功能详见 [MARKERS.md](MARKERS.md)。
