# 标记（Markers）

> **English (source of truth)**: [../MARKERS.md](../MARKERS.md)

标记是用户自定义的、按关卡划分的触发点（R10）。游玩中当标记条件满足时，记录其在该分段内的**首次**触发时间，并与该关卡自身的 PB 记录对比。标记数据**仅限本地**——不提供导入他人数据的功能，与 subsegment 模块的 PB + LoadPath 双来源模型明确区分。

## 概念

- 每个 **(关卡, 类别键)** 对应一套标记。类别键遵循 subsegment 规则（R8.2.4）：无启用标签时为 `Any`，否则为按字母序排序的启用标签 id，以 `+` 连接。
- 标记的时间口径是触发帧的**分段时间**：`t_ms = round((GameTime - SegmentStart) * 1000)`——与 HUD 的"分段时间"行及 subsegment IL 对比同源。
- 每次关卡尝试中，每个标记只记录**首次**触发。触发记录与排行榜 feed 在进入关卡、一键重试、暂停菜单重开关卡、手动重置、离开关卡时清空；PB 保留。

## 标记类型（R10.1.4 / R10.2）

| 类型 | 触发条件 |
|------|---------|
| **范围触发** | 本地玩家位置位于轴对齐包围盒内（每个轴 `|p - center| <= size/2`），并且（若启用）"抓取任意物体"（`GrabManager` 至少抓取 1 个物体）与"跳跃"（`Human.jump`）条件同时成立；玩家须处于可操作状态（非 Spawning / Unconscious / Dead）。任一边长 ≤ 0 的盒子永不触发并在编辑器中提示。 |
| **存档点触发** | **碰触**（默认）：进入 `PlayingLevel` 后首次 `Game.currentCheckpointNumber >= N`（用 `>=` 兼容 Dark 等非线性存档点关卡）。**加载**（勾选"从暂停菜单加载时触发"）：由暂停菜单 Load 点击回调触发，要求 `currentCheckpointNumber == N` 精确相等——暂停菜单始终加载*当前*存档点，因此该判定是精确的。 |
| **抓取物体** | 捕获的物体被本地玩家抓取（父子包含关系任一方向皆可，与 `GrabManager.IsGrabbed` 语义一致）。 |

同一帧满足多个标记时全部记录（feed 内按定义顺序）。

## PB（R10.3）

- **整关 PB 集合**：当本关**通过**、**非**一键重试、且成绩**有效**（无 R5 无效标记）时，以本关分段时间与已存 `pb.total_ms` 比较；仅当**严格更优**时，把这一趟所有标记的触发时间整体写入新 PB。
- 本次未触发的标记不写入对应条目（显示 `--`）。
- 删除标记会一并删除其 PB 条目。
- PB 写入发生在自动重置清除分段之前（与 subsegment PB 写入同一时刻，R8.3.3.1），采用原子替换（临时文件 + rename）。

## 数据文件

`<config>/HSRTimer/markers/{关卡}/{类别}.json`（UTF-8，格式化 JSON；由显式序列化器写出，因此每个字段——包括空的 `markers` 数组——都必然存在，读取时容错）：

```json
{
  "format_version": 1,
  "level_id": "Aztec",
  "level_source": "BuiltIn",
  "level_number": 8,
  "category_key": "Any",
  "pb": { "total_ms": 184320, "created_at": "…" },
  "markers": [
    { "id": "m1", "name": "Tower", "type": "Range", "enabled": true,
      "cx": 1.0, "cy": 2.0, "cz": 3.0, "sx": 2.0, "sy": 4.0, "sz": 2.0,
      "requireGrab": false, "requireJump": true,
      "checkpointIndex": 0, "triggerOnLoad": false,
      "objectSceneId": 0, "objectPath": "", "objectName": "", "ox": 0, "oy": 0, "oz": 0 }
  ],
  "pbTimes": [ { "id": "m1", "t_ms": 12345 } ]
}
```

- 关卡 key 与 subsegment IL 目录同规则（R8.2.3）：BuiltIn / EditorPick 用英文本地化关卡名，工坊用数字 Workshop id，本地工坊无 id 时用关卡文件夹名（保证面板中创建的标记在游玩时解析到同一 key）。
- 文件缺失、损坏或不支持的版本一律视为空标记集并记录警告，绝不影响计时。

## 编辑（R10.4 / R10.5）

设置面板 → **标记** 标签页：

1. 打开**标记编辑模式**（持久化）。开启后计时器 HUD 最底部显示一行醒目提示（不依赖 `show_hud`；HUD 隐藏时显示在左下角）。提示正下方会显示类似 3D 编辑器轴向指示器的小型 XYZ 轴，跟随当前视角旋转，包括 F8 自由视角。
2. 选择关卡分组——**主梦境**（内置）、**额外梦境**（editor pick）、**工坊**——并进入一个关卡。主梦境列表还包含最终战役关 **Reprise**（`Intro_Reprise`，BuiltIn 12）——该关未被游戏内置工坊仓库枚举，因此由标记模块显式补上。
3. **新建标记**（仅编辑模式显示）创建一个 `Range` 标记并展开其编辑器：名称、类型下拉与各类型控件。
   - 范围触发："设为玩家位置"（需在关卡内有本地玩家）、中心 X/Y/Z、边长 X/Y/Z、"抓取 / 跳跃"条件开关。
   - 存档点触发：存档点序号、可选的"从暂停菜单加载时触发"。
   - 抓取物体："设为当前抓取物体"——未抓取任何物体时提示；抓取超过一个物体时提示**无效**；恰好一个时写入物体引用（有 sceneId 用 sceneId，否则记录层级路径，另存名称与位置用于兜底解析）。
4. 改动自动保存（每帧至多落盘一次，并在面板保存 / 关闭、游戏退出时强制落盘）。

若关卡元数据（`WorkshopRepository`）尚未加载（例如从未打开过选关界面），关卡列表会显示提示而不会臆造关卡 key；进入一次主菜单选关界面后点 **刷新** 即可。

## 可视化（R10.6）

**编辑模式开启**且关卡进行中时：

- 每个启用的**范围**标记绘制一个蓝色半透明立方体（颜色由 `OverlayFillColor` 配置，默认 `3F7FFF66`），中心以白色文字显示标记名；
- 每个启用的**抓取物体**标记用同一立方体 + 标签高亮其已解析目标的包围盒。

叠加层使用 `Graphics.DrawMesh` + 透明 unlit shader——不创建碰撞体、不修改任何游戏物体 / 材质，不影响玩法与联机。若找不到可用 shader，则自动降级为一次 IMGUI 线框投影。无法解析的抓取目标每关记一次警告并跳过绘制；请在编辑器中重新捕获该物体。

## 排行榜 feed（R10.7）

共享排行榜 HUD（屏幕左侧，由排行榜模式循环键在“关闭 → 分段对比 → 标记 → 关闭”之间循环）在 **排行榜** 设置页提供内容切换：**分段对比** 或 **标记**。排行榜顶部固定在屏幕垂直中心（加上配置的纵向偏移），因此内容始终向下延伸。

标记模式下：

- **标记触发时新增一行**——未触发的标记不占位。
- 行格式：`{标记名}: {时间}`。时间由 `Markers.LeaderboardTimeMode` 决定（默认 `Relative`）：**绝对** = 该标记的分段时间（`MM:SS.mmm`）；**相对** = 与该标记 PB 的带符号差值（`+MM:SS.mmm` / `-MM:SS.mmm`）。相对模式下无 PB 条目时显示 `--`。
- **最新触发的行插入标题正下方**，旧行整体下移（不重排、不截断）。
- 领先 / 落后 / 持平颜色始终生效：比 PB 快 = 绿色，慢 = 红色，持平 / 无 PB = 白色；两种时间模式下都如此。
- feed 在关卡结束的过渡期保留（上一关的 feed 保留到下一关首次触发才替换）；若下一关没有标记，则在关卡开始即清空。
- 切换模式不影响 subsegment 的采样记录与 PB 写入。

## 排错

- **标记一直不触发**——检查：是否启用？范围边长是否 > 0？玩家状态是否可操作（非死亡 / 无意识 / 出生）？"抓取 / 跳跃"条件是否在满足时同时成立？存档点触发是否与 `Game.currentCheckpointNumber` 一致？
- **抓取物体标记失效**——目标在本关无法解析（物体被改动或是动态生成的）。用"设为当前抓取物体"重新捕获；日志中每关会有一条警告。
- **切换标签后 PB"消失"**——标记集按类别键隔离，切换标签会指向不同的文件；切回原标签即可看到旧数据。
- **关卡列表为空**——先进入一次主菜单选关界面让游戏填充 `WorkshopRepository`，再点 **刷新**。
- **叠加层不显示**——确认编辑模式已开、正在关卡内、且 `Markers.Enable` 为 true；开启 `Markers.DebugLogging = true` 后日志会显示关卡 key 与标记数。

`[Markers]` 设置见 [CONFIG.md](CONFIG.md)，完整规格见 [REQUIREMENTS.md](../REQUIREMENTS.md) R10。
